KatieCAD - Third-party software
==================================================================================

AppImage and archive) also contain the following open-source components.
Each one stays under its own license. The full license texts are in the
"licenses" folder next to the program; the exact versions included in a
package are listed in licenses/VERSIONS.txt. The source code of every
component is publicly available at the addresses below.

Which of the "needed by" packages end up in a package depends on the
versions used for the build; licenses/VERSIONS.txt lists what is really
included.

LibreDWG (GPL-3.0-or-later, https://www.gnu.org/software/libredwg/) is NOT
part of KatieCAD. If the user has installed it separately, KatieCAD can start
its program dwg2dxf as an optional fallback for reading DWG files.

Own work: the single-stroke fonts "ISO" and "ISO kursiv", the symbol library,
the title blocks and the report templates are covered by the KatieCAD license.
Fonts installed on the user's computer are only read when needed and are not
copied or delivered.

The build tools Inno Setup and appimagetool are not part of the program.
